# Study Hours and Exam Score Relationship Analysis

## About the Project
This project explores the relationship between study hours and exam scores using Python, Pandas, and Matplotlib.

## Objective
To understand how visualization can reveal relationships between two numerical variables.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
The dataset contains 20 sample student records with study hours and exam scores. It was created for learning purposes.

## Steps Performed
1. Created a dataset with two numerical variables.
2. Explored the data using Pandas.
3. Created a scatter plot using `plt.scatter()`.
4. Calculated the correlation coefficient.
5. Described the observed relationship and recorded at least three observations.

## Observations
- The sample shows a positive relationship between study hours and exam scores.
- Scores generally increase as study hours increase in this dataset.
- The correlation coefficient summarizes the direction and strength of the linear relationship.
- Correlation does not necessarily mean causation.

## Conclusion
This project demonstrates how a scatter plot and correlation coefficient can help explore relationships between numerical variables.
